CONTEXT
================================================================================

PADDOCK currently tracks horse health events, injuries, duty assignments,
medications, and inspections — but there is no way to see how these relate
to each other. The regiment needs to understand patterns such as:

  "Does 6 months on TRAINING_WING correlate with higher injury rates?"

This feature adds a /welfare analytics page that aggregates existing data
into fleet-level insights, duty-to-outcome correlations, per-horse risk
scores, and rule-based predictive alerts.

No database schema changes required — all data already exists across the
DutyAssignment, InjuryReport, HealthEvent, MedicationRecord, and
Inspection models.

PHASE 2: ANALYTICS ENGINE
================================================================================

4. CREATE CORE ANALYTICS MODULE
   New file: src/lib/welfare-analytics.ts
   Server-side only. Uses Prisma directly (same pattern as dashboard).

   Four functions:

   A) getFleetOverview()
      - Task readiness distribution (groupBy taskReadiness)
      - Injury trend: InjuryReport grouped by month (last 12 months),
        counted by severity
      - Health compliance: HealthEvent counts by status per type
      - Active medication withdrawal count

   B) getDutyCorrelation()
      - Fetch all DutyAssignments + InjuryReports for active horses
      - For each injury, find the overlapping duty assignment where
        startDate <= reportedAt AND (endDate IS NULL OR endDate >= reportedAt)
      - Compute per station:
        * Injury rate (injuries per horse-month)
        * Average days at station before first injury
        * Body location frequency
      - Normalise free-text bodyLocation into categories:
        Hoof, Front Limb, Hind Limb, Back, Head/Neck, Chest/Shoulder, Other

   C) computeHorseRiskScores()
      - Single query: all active horses with recent duty assignments,
        injuries (last 6 months), overdue health events, inspections (last 6 months)
      - Score algorithm (0-100, higher = more risk):

        FACTOR                          MAX PTS   CALCULATION
        ---------------------------------------------------------------
        Time at current station         20        min(months/9, 1) x 20
        Recent injuries (6mo)           25        Weighted count:
                                                  SEVERE x 1.5
                                                  MODERATE x 1.0
                                                  MINOR x 0.5
                                                  min(weighted/3, 1) x 25
        Overdue health events           15        min(count/2, 1) x 15
        Age factor                      15        Under 5 -> 10
                                                  Over 18 -> 15
                                                  Over 15 -> 8
                                                  Otherwise -> 0
        Inspection failures (6mo)       15        FAIL=1, ADVISORY=0.5
                                                  min(weighted/2, 1) x 15
        Current readiness degradation   10        NON_TASKWORTHY = 10
                                                  LIMITED_ROLE = 5
                                                  FULL_EXERCISE = 0

      - Risk levels derived from score:
         0 - 25   LOW        (green)
        26 - 50   MODERATE   (amber)
        51 - 75   HIGH       (orange)
        76 - 100  CRITICAL   (red)

   D) generatePredictiveInsights()
      Rule-based alerts using risk scores + historical station data:

      Rule 1: STATION DURATION WARNING
      If horse has been at TRAINING_WING or KINGS_LIFE_GUARD for > 5 months
      and the historical injury rate at that duration is elevated compared
      to baseline, generate alert.

      Rule 2: RECURRING INJURY PATTERN
      If a horse has 2+ injuries to the same body location in the last
      12 months, flag as "recurring injury site".

      Rule 3: HEALTH COMPLIANCE FAILURE
      If a horse has 2+ overdue health events, flag as "health compliance
      failure — increased risk of undetected conditions".

      Rule 4: POST-INJURY RETURN RISK
      If a horse returned from NON_TASKWORTHY or LIMITED_ROLE to
      FULL_EXERCISE within the last 30 days and has a prior SEVERE injury,
      flag as "recently returned to full duties — monitor closely".

      Rule 5: AGE-WORKLOAD MISMATCH
      If horse is > 16 years old and currently at KINGS_LIFE_GUARD
      (highest ceremonial workload), flag for review.

     Name | Regt No | Station | Role | Risk Score | Top Risk Factor | Readiness

   - Horse name links to individual horse profile

10. RiskScoreBadge.tsx
    - Small reusable badge component
    - Displays score number with colour coding (green/amber/orange/red)

11. PredictiveInsightsTab.tsx
    - Alert cards grouped by risk level (CRITICAL shown first)
    - Each card shows: horse name (linked), alert type, message,
      recommendation text
    - Station summary panel: "N horses approaching risk threshold at
      TRAINING_WING"
    - Confidence note when historical data is limited
